# xv-agents

Skills that make the seven agents of Xtreme Vibing (XV) real: the watch, the forecaster, the scenario agent, the maker, the cleaner, the guardian, and the listener. Each agent is a skill in the open Agent Skills format, so any harness that reads skills can run it.

Status: v0.1 is being built. This README is finished at the end of the build.

## The one rule

An agent may stop. It may not decide. A person is responsible for every change, including one made entirely by agents, so the harness is built to hand back, not to approve. There is no agent that says yes.
