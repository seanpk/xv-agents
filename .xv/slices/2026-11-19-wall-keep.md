# Wall marks are kept by file and test, and xv step writes a stop in one place

## Scenario

Wall marks are kept by file and test, and xv step writes a stop in one place.

1. When a guardian pass reports wall recommendations, a recommendation that a person accepted on an earlier pass keeps its mark only when the new pass names the same file and test. An accepted recommendation for `test_x` in `tests/a.py` stays on the record when the next pass names `test_x` only in `tests/b.py`, and the `tests/b.py` recommendation is not accepted.
2. A recommendation that a person refused on an earlier pass is matched the same way, on file and test.
3. In `xv step`, the budget stop before a step and the `repass_diff_failed` stop write the stop, save the record and reach the seat through one shared piece of code. Each stop's record entry, log line, message to the seat and exit stay as they are now.
4. A line in CHANGELOG.md.

records written before this change; the other stop blocks in scripts/run.py
