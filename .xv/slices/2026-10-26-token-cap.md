# The token cap counts the tokens that drive cost

## Scenario

The budget's token cap counts input, output and cache-write tokens, not cache reads. On the thundercloud slice in #28, the steps so far had 393,030 tokens, of which 359,933 were cache reads, 28,082 cache writes, 26 input and 4,989 output. They count 33,097 against a 150,000 cap, so the cap does not fire before the dollar cap ($0.159 of $1). The forecaster's token forecast and new rows of the estimation guide use the same count, so a person sets the cap on the number it is checked against.
