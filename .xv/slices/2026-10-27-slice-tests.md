## Scenario

Tests a slice leaves behind fit the test layout and do not go stale. (1) The scenario brief asks for new tests in the existing test file for the code under test, and a new file only when none exists (`skills/scenario/SKILL.md` step 6 says the opposite today). (2) The scenario agent marks each test that only proves the slice did its job and has no value after it (for example, "this file is `.ts`, not `.js`"). Its report names them, and the record keeps the list. At close, the close output lists them for the person who set the work going, who approves each removal; a removal is a recorded move. Nothing is removed without that approval. (3) When a recorded move (`xv record move`) moves or deletes a file that `red.files` names, the record's `red.files` and `red.command` are updated to match, so the guardian and the "watch the first green run" line do not point at a deleted file. (seanpk/xv-agents#17; Sean approves the brief change, solo.)

Settled at the scenario's stop, 2026-10-27, Sean: (1) `xv record move` takes `--to <new path>` for a file that moved and `--deleted` for a file that was removed. (2) In `red.command`, the old file's path and its module name (`tests/test_x.py`, `tests.test_x`) are replaced with the new file's. When the last file in `red.files` is deleted, `red.files` is empty, `red.command` is null, and the log says why. (3) The scenario report gets a `slice_only` field: a list of `{"file", "test", "why"}`. The record keeps it as `slice_only`. (4) In Sean's words: "I think the scenario only tests should be removed automatically unless an agent discovers a reason for keeping (any of) them. In which case the message would explain the recommendation to add it". So no approval stop: after the suite is green, the cleaner removes each slice-only test as a recorded move marked slice-only. Those moves do not raise the `accept_moves` stop, and the packet lists them on one line. When the cleaner or the guardian finds a reason to keep one, it stays, and the packet names the test and says why it recommends keeping it.
