# Standards

The cleaner's rules, earned by misses. The cleaner applies them without asking and never edits this file. A rule enters when the person who set the work going accepts it from a packet. A rule that changes the shape or restates the pitch is not a standard.

An empty file at the start is correct. An empty file after a month of comments is the practice declined.

Each rule is a heading and these lines:

```
### <the rule, one line>
- added: <date> by <name>
- from: <slice id>, <the moment in the record>
- miss: <what went wrong without it>
- seen: [<repo>@<date>]
- check: <the script, lint rule or test that enforces it, or "none: judgement">
```
